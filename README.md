# MediaGo - LazyCat App

Cross-platform video downloader — sniff and grab m3u8/HLS streams, Bilibili, YouTube and more.

## 上手指南

1. 打开应用
2. 粘贴视频链接
3. 选择下载格式和质量
4. 开始下载

## 开发

```bash
# 构建 LPK 包
lzc-cli project release -o mediago.lpk

# 查看包信息
lzc-cli lpk info mediago.lpk
```
